## Contributing
Decide in which category you want your function to be fit. For example, strings, math, lists, etc.

Let's say that you will create a function which is returning the sum of two numbers, and let's say you call it sum. 

In this case, create a new file sum.py inside math folder (create one if there is no folder that matches your function's category inside ofun folder).

Start your function name with an ofun_ prefix, so, your function will be something like the following:
> def ofun_sum(fval, sval):

# Check and push your function and leave the rest to the community to learn and grow together.
